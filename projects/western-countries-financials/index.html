Western Countries Financial Analysis

A financial analytics capstone that connected spreadsheet exploration and SQL validation with a Power BI report.

Excel, SQL, Power BI · Coursework project · 2023

Download my original PowerPointView project files on GitHub

What I built

  • Explored financial data in Excel and calculated profit and discount percentages.
  • Imported records into a SQL database and queried country performance and product rankings.
  • Built dashboard filters and comparisons for sales, profit, discounts and units sold across countries, products and segments.

What the analysis showed

The original dashboard displayed 118.73M in sales, 16.89M in profit and 1.13M units sold. These are dataset totals. A relationship between discounts and sales alone does not establish that discounts caused higher sales.

Skills demonstrated

Data preparation, measure definitions, visual analysis, dashboard design, and communicating findings for business decisions.
